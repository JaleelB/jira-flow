# JiraFlow v1

JiraFlow v1.0.0 is a complete rewrite of JiraFlow in TypeScript and Bun.

It introduces a headless engine and OpenTUI management interface, safe
`commit-msg` hook ownership and composition, worktree-local issue linking,
repository management, PR-title generation, Doctor/repair, and runtime-free
native executables. Git remains repository authority; JiraFlow does not require
Jira, GitHub, or `gh` APIs.
